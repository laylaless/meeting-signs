台签设置

标准模版：内容限制在 190×178mm 方框内（A4 居中），上半倒转 + 下半正向（对折立放后两面均正向），默认华文新魏 155 号（所有名字字号统一，超宽自动横向压缩不换行），沿方框上下对折立放。字体可选华文新魏 / 黑体 / 宋体 / 楷体 / 华文楷体，或选「自定义字体…」输入本机已安装的任意字体名。
对折大台签：A4 纵向打印后沿中线对折，立放于桌面，正反两面均可读。紧凑小台签：按虚线裁切后逐条对折。字号填 0 时按模版默认（标准 155pt），也可手动指定。

会场编辑

100%

桌型三种：长条桌（对坐）、圆桌、主席台。拖动桌子调整位置，选中桌子后在「桌子属性」里调座位数 / 旋转 / 翻转；滚轮缩放，拖空白平移。
排座：点击名单即自动指派到第一个空位（或先点座位再点名单指定座位）；把右侧名单中的人拖到座位上即指派；拖座位上的人到另一座位为移动（两人互换）；拖到空白处撤销；双击座位清空；右键座位 = 禁用/恢复（灰色斜纹座不参与排座）。序号规则：1 号位居中，2 号位在 1 号领导左手侧（图面右侧），依次向两侧展开，可用每桌「翻转」切换朝向。
导出/导入备份（banner 右上角）：把当前会场布局、排座、名单和会议室库存成文件备用或换电脑使用；导入后自动保存在浏览器里（刷新不丢）。「恢复默认」重置台签/座位设置（名单保留）。
