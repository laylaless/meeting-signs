# 会议台签与座位图助手

[在线访问](https://laylaless.github.io/meeting-signs/)

单文件 Web 应用（`index.html` + `font/` 字体目录），零依赖、无需安装、无需联网，为会议筹备提供三件事：

1. **台签打印** —— 按名单批量生成桌牌，浏览器直接打印
2. **座位示意图** —— 三种桌型自由布局 + 礼宾序自动排位，可打印 / 导出 PNG
3. **会标** —— 会议名称 + 日期画面，会场大屏 / LED / 投屏全屏显示

数据全部保存在浏览器本地（localStorage），刷新、关闭浏览器不丢失。

## 快速开始

- 双击打开 `index.html` 即可（推荐 Chrome / Edge），也可放内网共享目录发给同事
- **分发必须带上 `font/` 文件夹**：内置华文中宋、华文新魏字体（@font-face 加载），目标电脑没装字体也能正常显示；若确认对方装有 Office 相关字体也可不带（自动回退系统字体）
- 通过网页服务器（如内网 http）访问时，点击版本号可直接读取同目录 `UPDATE.md` 更新记录；双击直接打开时显示内置同步记录

## 名单（一切的起点）

- 每行一人：只写姓名，或「姓名｜职务」（也支持逗号、空格、tab 分隔）
- **按住行上下拖拽**调整顺序（也支持 ↑↓ 按钮、触屏拖拽）—— **名单顺序 = 礼宾次序**，台签与自动排座都按它执行
- 名单独立保存，重置台签 / 座位 / 会标时保留

## 台签打印

| 模版 | 说明 |
|---|---|
| **标准模版**（默认） | 内容限制在 190×178mm 方框内（A4 纵向居中、带细边框），上半正向 + 下半倒转，**华文新魏 96 号**（同 Word 数字字号、所有名字统一），沿方框上下对折立放 |
| **对折大台签** | A4 纵向 1 人/页，上半正向 + 下半倒转，沿中线对折立放，正反两面可读 |
| **紧凑小台签** | A4 按虚线裁切成条、逐条对折立放（默认每页 4 条，可调 2–8） |

- **字体**：华文新魏 / 黑体 / 宋体 / 楷体 / 华文楷体 / 自定义字体名（本机已安装即可，留空回退华文新魏）；标准模版不锁字体，可自由选择
- **字号**：默认自动（标准模版固定 96pt 统一；其余按姓名字数缩放），可手动指定（单位 pt，0 = 自动）
- 可选名字上方显示职务小字（约 21pt）、可选加粗
- **打印设置**：纸张 A4、边距「无」、取消页眉页脚、缩放 100%

## 座位示意图

三种桌型随意组合：**长条桌（对坐）**、**圆桌**、**主席台**。

### 布局编辑

- **添加桌子**：顶部三个按钮；新桌自动避开已放置的桌子（网格找空位），添加后画布视角自动平移到新桌
- **拖动桌子**自由摆放；选中后在「桌子属性」面板调座位数（长条桌分上 / 下侧，单侧上限 50；左右端面各 0~50，端面多时桌子自动加长）、旋转 90°、**翻转**（礼宾朝向镜像）、删除（或 Delete 键）
- **桌子管理**表单：每桌一行编辑编号、↑↓ 调编号顺序（礼宾序按桌号从前到后）；标题行「全清」一键清空桌子与排座（名单保留）
- **视图**：滚轮缩放（以鼠标为中心）/ ➖➕ / 「适应」铺满（1% ~ 400%）；拖空白或**按住中键**平移（中键在桌上也只平移，不选中不拖动）
- **撤销 / 重做**：画布右上角 ↶ ↷ 或 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z；快照式最多 50 步，覆盖加桌 / 拖动 / 排座 / 改名 / 导入等全部改动（不跨刷新）

### 礼宾排位规则

- **1 号位居中，2 号在 1 号左手侧（图面右侧）**，依次左右交替向外；圆桌 1 号在底部中央；全场按桌号连续编号
- **长条桌对坐**：1 号正对面是对面一侧最高位，2 号对面是对方第 3 位、3 号对面是对方第 2 位（每侧 4 人时 3124 / 6578）；「翻转」整桌镜像，对齐关系不变
- **长条桌端位**：左 / 右端座位独立设置（各 0~50），放桌子两端外侧，序号排上下侧之后（图纸右端先、每端从上到下），适合工作人员 / 记录位

### 指派与调整

- **拖拽**：名单里的人直接拖到座位即指派；拖到另一座位为移动（有人则互换）；拖到空白处撤销指派
- 点击座位选中后再点名单同样指派；双击座位清空
- **右键座位**：切换禁用 / 启用（灰色斜纹）；禁用座位不参与排座、指派、拖拽，序号自动重排
- 座位上方蓝色小数字 = 礼宾序号（可开关）
- **打印（A4 横向）/ 导出 PNG**：按当前画布缩放输出（屏幕多大图多大）；超出 A4 可打印区自动等比缩回

### 会议室库与备份

- **保存为会议室**：摆好布局后命名保存（「三楼大会议室」…），只存桌子布局（桌型、座位数、位置、旋转、编号），不含名单与排座；同名再存即覆盖；可存任意多个，一键载入（自动「适应」居中）/ 删除
- **导出会场 JSON**：名单 + 桌子布局 + 排座结果 + 视图状态 + **全部会议室库** 存成一个 `.json`（文件名带日期时间）
- **导入会场 JSON**：确认后整体替换；会议室库按名称合并（同名覆盖、新名追加，旧格式无库数据则不动）；导入自动存 localStorage
- **跨电脑迁移**：A 机导出 → 拷贝文件 → B 机导入即可

## 会标

会议名称 + 日期画面，会场大屏 / LED / 投屏用。左侧编辑右侧实时预览。

### 内容与多会标

- 会议名称多行文本，**手动换行原样保留**；日期选择器，画面显示「2026年9月9日」
- **多会标**：新增 / 删除（至少留一个）、点选切换；**新增 = 复制当前全部配置**；列表顺序即切换顺序；默认两个（66/30 大横幅 + 32/24）

### 版式与文字

- **画面比例**：16:9 / 4:3 切换（保比例预览）
- **默认布局**：名称距上 25%、日期距下 15%；**上下拖动**微调（左右锁定居中），拖动时显示距上 / 下百分比，双击复位，全屏沿用
- **字号**：名称 / 日期分别可调（PPT 字号 pt）
- **字间距**：统一设置（默认 3pt，随画面比例等比）
- **行距**：统一设置（默认 1.5 倍，随字号自动缩放）
- **字体**：默认华文中宋（自托管 `font/STZHONGS.ttf`），可选黑体 / 宋体 / 楷体 / 华文新魏 / 华文楷体 / 自定义字体名
- **颜色**：背景默认政务红 `rgb(165,38,21)`（预设 `rgb(193,0,0)`，拾色器 / 16 进制自定义）；文字默认黄（预设金黄 / 白）
- **文字阴影**：名称与日期共用，PPT 参数——颜色、透明度（%）、角度（°）、距离（pt）、模糊（pt）；默认黑 60% 透明、45°、8pt、模糊 3pt
- 以上字号 / 偏移 / 阴影 / 间距均按画面高度（基准 1080）**等比渲染**，预览、全屏、任意屏幕下视觉占比恒定

### 全屏

- 「⛶ 全屏显示」只留画面、配置全隐藏；**↑↓ 切换会标**，ESC 退出；进入后右下角 3 秒操作提示
- 会标随会场 JSON 一起备份；localStorage 持久化；支持撤销（Ctrl/Cmd+Z）

## 其他

- **恢复默认**：banner 右上角「↺」，重置台签 / 座位 / 会标设置与排座（名单保留，会标日期回到当天）
- **1.0 旧版存档**：`index_v1.html` 为座位图 1.0（固定 SVG 模板：主席台 / 圆桌 / 长条桌 1~4 排 / U 形），独立存储 `meeting-signs-v1-archive`，与 2.0（`meeting-signs-v4`）互不影响、可并存

## 常见调整

- 台签字太大 / 太小 → 字号手动指定（pt），0 = 自动
- 主席台人多座位变窄 → 正常，自动压缩
- 换浏览器 / 电脑数据丢失 → localStorage 是本地存储；用「导出会场 JSON → 导入」迁移
- 误删桌子 / 排错座 → Ctrl+Z 撤销（最多 50 步）或 ↶ 按钮
- 「适应」后桌子太小 → 桌多场大属正常，滚轮放大局部或删减桌子
