# 会议台签与座位图助手

[在线访问](https://laylaless.github.io/meeting-signs/)

单文件 Web 应用（`index.html` + `fonts/` 字体目录），零依赖、无需安装、无需联网。用于会议筹备时：

1. **台签打印** —— 按名单批量生成桌牌，直接用浏览器打印
2. **座位示意图** —— 常用会场布局模板 + 自动礼宾排位，可打印 / 导出 PNG（长条桌上/下侧座位数 0~50 任意加）

## 使用方法

双击打开 `index.html` 即可（推荐 Chrome / Edge）。也可以放内网共享目录，发给同事直接用。

**分发注意**：`index.html` 必须和 `fonts/` 文件夹一起拷贝（内嵌华文新魏字体，5MB）。若目标电脑装了 Office，也可以不用带 `fonts/`——应用会自动回退到系统里的华文新魏。

### ① 名单

- 每行一人；可只写姓名，或「姓名｜职务」（也支持逗号、空格、tab 分隔）
- **按住行上下拖拽**调整顺序（也可用 ↑↓ 按钮，触屏同样支持拖拽）—— **名单顺序 = 礼宾次序**，台签打印与自动排座都按它执行
- 数据自动保存在浏览器本地（localStorage），下次打开仍在

### ② 台签打印

默认版式为**标准模版**。

| 样式 | 说明 |
|---|---|
| 标准模版 | 内容限制在 **190×178mm 方框**内（A4 纵向居中、带细边框），上半正向 + 下半倒转，**华文新魏 96 号**（同 Word 数字字号，所有名字字号统一），沿方框上下对折立放 |
| 对折大台签 | A4 纵向 1 人/页，上半正向 + 下半倒转，打印后沿中线对折立放，正反两面可读 |
| 紧凑小台签 | A4 按虚线裁切成条，逐条对折立放（默认每页 4 条，可调 2–8） |

- 字体：华文新魏 / 黑体 / 宋体 / 楷体 / 华文楷体，或「自定义字体…」输入本机已安装的任意字体名（留空回退华文新魏）
- 字号默认自动（标准模版固定 96pt、所有名字统一；其余按姓名字数缩放），也可手动指定
- 可选在名字上方显示职务小字（约 21pt）、可选加粗
- 打印时请在浏览器打印设置中确认：纸张 A4、边距「无」、取消页眉页脚、缩放 100%

### ③ 座位示意图 2.0（canvas 自由布局）

三种桌型随意组合：**长条桌（对坐）**、**圆桌**、**主席台**。

会场编辑：

- **添加桌子**：顶部三个按钮；新桌**自动避开已放置的桌子**（按网格找空位），添加后**画布视角自动平移到新桌子**；**拖动桌子**自由摆放
- 选中桌子后在「桌子属性」面板：调座位数（长条桌分上/下侧，单侧上限 50；左右端面各 0~50，端面座位多时桌子自动加长）、**旋转 90°**、**翻转**（礼宾朝向）、删除（或 Delete 键）
- **桌子管理**表单：每张桌子一行，编辑编号、↑↓ 调整编号顺序（礼宾序按编号从前往后排）；标题行「全清」按钮一键清空所有桌子与排座（名单保留）
- **缩放**：滚轮（以鼠标为中心）/ ➖➕ 按钮 / 「适应」一键铺满（缩放范围 1% ~ 400%）；拖空白处或**按住中键拖动**平移画布（中键在桌子上也只平移、不会拖动/选中桌子）
- **撤销 / 重做**：画布右上角 ↶ ↷ 按钮，或 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z；快照式，最多回退 50 步，覆盖加桌/拖动/排座/改名/导入等所有改动（不跨刷新会话）

排位与操作：

- 一键排位规则：**1 号位居中，2 号位在 1 号领导左手侧（图面右侧）**，依次左右交替向外展开；圆桌 1 号位在底部中央；全场按桌号顺序连续编号
- **长条桌对坐**：1 号正对面是对面一侧的最高位次，2 号对面是对方第 3 位次，3 号对面是对方第 2 位次（每侧 4 人时上排 3124、下排 6578）；「翻转」整桌镜像，对齐关系不变
- **长条桌端位**：属性面板「左端座位」「右端座位」分别设置（各 0~2 个），放桌子两端外侧；序号排在上下侧之后（图纸右端先、每端从上到下），适合工作人员 / 记录位，也可拖拽手动调
- **拖拽**：把右侧名单中的人直接拖到座位上即指派；拖动座位上的人到另一座位为移动（目标有人则互换）；拖到空白处撤销
- **右键点击座位**：切换禁用/启用（灰色斜纹标记）；禁用的座位不参与排座、指派与拖拽，序号自动重排
- 点击座位选中后点名单也可指派；双击座位清空；座位上方蓝色小数字 = 礼宾序号（可开关）
- 打印（A4 横向）或导出 PNG：均按**当前画布缩放比例**输出（屏幕上多大，图里就多大）；打印时若超出 A4 可打印区自动等比缩回，缩放比例小时至少铺满页面

**会场配置 JSON 导出 / 导入**：

- 「📥 导出会场 JSON」：把当前名单、桌子布局、排座结果、视图状态，**以及会议室库里的全部会议室**一起存成一个 `.json` 文件（文件名带日期时间），可备份、可传给别人
- 「📤 导入会场 JSON」：选择之前导出的文件，确认后整体替换当前数据；会议室库按名称合并（同名覆盖、新的追加），旧格式文件无会议室数据则不动本机库；导入后**自动保存在浏览器 localStorage**（刷新、关浏览器不丢）
- 两台电脑迁移会场：A 机导出 → 拷贝 JSON 文件 → B 机导入即可（会议室库一并带过去）

**会议室库（多会议室存取）**：

- 摆好桌子布局后，在左侧「会议室库」输入名称点「💾 保存为会议室」，可保存任意多个会议室（如「三楼大会议室」「小会议室」）
- 保存的只是**桌子布局**（桌型、座位数、位置、旋转、编号），不含名单与排座——换一场会直接载入、导入新名单重排
- 列表里一键「载入」（替换当前画布并清空排座，名单保留）或「删」；同名称再保存即覆盖更新
- 会议室库独立存在浏览器里，刷新不丢；跨电脑迁移用「导出会场 JSON」（会议室库随文件一起带走）

## 1.0 旧版存档

`index_v1.html` 是座位图 1.0（固定 SVG 模板版：主席台/圆桌/长条桌 1~4 排/U 形）的完整存档，功能与重构前一致，测试全过。它使用**独立的浏览器存储**（`meeting-signs-v1-archive`），与 `index.html`（2.0，`meeting-signs-v4`）互不影响，两者可并存使用。

## 常见调整

- 台签字太大/太小：字号输入框手动指定（单位 pt），0 = 自动
- 主席台人数较多导致座位变窄：正常现象，会自动压缩座位宽度
- 换了浏览器 / 换电脑数据丢失：数据存在浏览器 localStorage 里；换环境用「③ 导出会场 JSON → 新机器导入」迁移
- 误删桌子 / 排错座：Ctrl+Z 撤销（最多 50 步），或点画布右上角 ↶
- 「适应」后桌子太小：桌子多时场地大，属正常；可滚轮放大局部查看，或删减桌子
